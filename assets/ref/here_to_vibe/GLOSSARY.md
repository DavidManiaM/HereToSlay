# Here to Vibe (Code) — glossary

Table language is **Romanian**. Title: **Here to Vibe (Code)**.

Mechanics follow Here to Slay except the locked changes in `QUESTIONS.md`
(Random.org all-rolls, Ce-Zar, 12 unique items, freeze/hack extras, masks).

---

## Vocabulary

| Original (EN) | Romanian / in-joke | Notes |
|---------------|-------------------|--------|
| Hand | **prompturi** | Cards in hand (mana = prompts) |
| Card (a single one) | **barfă** | One gossip slip |
| Cards (generic) | **răspuns de la AI** | Flavour for the deck |
| Action point | **prompt** | Spending AP = spending a prompt |
| Dice / 2d6 | **np.random()** | Rolls |
| Hero | **persoană** | Party member |
| Party Leader | **șeful grupului** | One per player |
| Monster | **bestie** | You **befriend** them; you do not attack |
| Attack a Monster | **încearcă să te împrietenești** | Costs 2 prompts, still a roll |
| Slay | **împrietenire** (reușită) | Bestie joins your group |
| Magic | **script** | Instant, then discard |
| Item (blessing) | **cheat** / unealtă | Equip on your persoană |
| Cursed Item | **hack** / unealtă blestemată | Equip on an opponent's persoană |
| Modifier | **download/upload speed** | Played into any roll |
| Challenge | **Șia all in** | Challenger wins ties |
| Discard | **înlătură** / **aruncări** | Discard pile = teancul de aruncări |
| Win | **primești legitimația lui Andrei** | Instant win, same two conditions |
| Frozen | **înghețat** | New: Aerul condiționat vs Rota-lorifer |
| Mask | **mască** `/n` | Equipped persoană counts as that class |

## Turn actions (flavour)

| Original | Cost | Romanian flavour |
|----------|------|------------------|
| Draw a card | 1 | Trage o barfă / un răspuns |
| Play persoană / cheat / script | 1 | Joacă din prompturi |
| Use a persoană's ability | 1 | Activează puterea (np.random()) |
| Befriend a bestie | 2 | Împrietenire |
| Discard hand, draw five | 3 | Aruncă tot, trage 5 |

Playing a persoană still lets you roll its effect **immediately, free**.
