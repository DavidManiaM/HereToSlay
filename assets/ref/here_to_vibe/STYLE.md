# Here to Vibe (Code) — art style

Living style guide. Update this if the user tightens the look after a batch.

---

## Default look

- **Medium:** digital illustration that reads as a card portrait.
- **Style:** playful anime-ish (clear shapes, saturated colour, lively
  expression) while the **face and body still look like the real person**.
  Not a chibi. Not a photoreal photo-bash. Not a full cartoon animal.
- **Likeness:** keep the person's actual features, hair, skin tone, build,
  and vibe. Stylize eyes/lighting/line a bit; do not invent a different face.
- **Mood:** fun, slightly heroic, tabletop-fantasy costume on a real person.
  Cute-but-capable, like the original game's energy, without copying its
  animal characters. Inside jokes (Siemens cake, orange juice, Digi, np.random)
  can show up as props.
- **Language:** the printed game is Romanian. Title of the game: **Here to Vibe (Code)**.
  Do not put English card titles on the illustration. Prefer no letters at all
  on the art; the UI will set Romanian names. Exception: **SiemensGPT** may
  show that product name on the tool. Same for concept leaders whose
  identity is the name: **Claude Max**, **Enemy_key.pem**, **Digi**,
  **Random.org**, and named scripts (**~ClassDestructor**, **SearchHistory**,
  **Swap**, **NotSoRandom.org**, **Microsoft Defender**, **BitDefender**,
  **GiveMeBabyOneMoreCard**, **SegmentationFault**).
- **Likeness groups:** two different Răzvans, two different Cezars. Do not
  reuse a face across those splits. Matei assigns cards. Other repeats still
  get a new costume/prop per card.

## Framing

- **Portrait illustration only.** No card frame, no title, no class label, no
  ability text, no roll number, no class icon. The GUI draws those.
- **Subject:** waist-up or full-figure, centered, readable at card size
  (small on the board).
- **Background:** simple, graphic, class-tinted. Not a busy photograph.
  A glow, a colour field, a few props — not a full location unless asked.
- **Circular photos:** many source shots are a round crop on black. Use **only
  the person inside the circle** as likeness. Discard the black void and any
  classroom/office behind them. Invent a new illustrated background that fills
  the whole frame.
- **Aspect:** prefer **3:4** (portrait). Square 1:1 is acceptable if the
  subject is a close bust. The client crops to fill, so keep the person in
  the center with a little breathing room.

## Class colour hints (background / accent, not a filter over the face)

| Class | Accent |
|-------|--------|
| Fighter | warm red / ember |
| Bard | magenta / rose | exception: **Vl-ADD** is rockstar black/gold, not pink |
| Guardian | blue / silver |
| Ranger | green / forest |
| Thief | gold / shadow |
| Wizard | cyan / arcane glow |
| Monster | darker, more menacing, still playful |
| Item / Magic | object as hero; class colour only if the user says so |

## Props

The user will name extra objects (e.g. a guitar for a Bard). Put them in the
character's hands or clearly on their person. Do not hide the face behind the
prop.

## What not to do

- Do not copy Unstable Games / TeeTurtle animal designs.
- Do not typeset the card.
- Do not change the person's identity (age, ethnicity, hair colour) unless
  the user asks.
- Do not add extra characters unless asked.
- Do not generate photoreal celebrity lookalikes of people who are not in
  the provided photo.

## Consistency across the set

- Same lighting language: soft key light, readable silhouette.
- Same level of stylization from card to card.
- Costume should suggest the **role** (Bard, Fighter, …) and the **ability**
  (steal, protect, destroy, music, …) without needing text.
